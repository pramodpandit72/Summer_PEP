# OpenAI APIs, Gemini APIs, and AI SDK Integration

---

# What is an AI API?

An AI API (Application Programming Interface) allows developers to use AI models in their applications without building or training the models themselves.

Using an AI API, an application can:

- Generate text
- Answer questions
- Write code
- Summarize documents
- Translate languages
- Analyze images (supported models)
- Generate embeddings

Example:

```
User
   |
Application
   |
AI API
   |
AI Model
   |
Response
```

---

# Why Use AI APIs?

Without AI APIs:

- Developers must train AI models.
- Training requires large datasets.
- Training needs powerful GPUs.
- Development takes a long time.

With AI APIs:

- Easy integration
- Ready-to-use models
- Fast development
- Regular model improvements
- Scalable AI solutions

# OpenAI API

## What is the OpenAI API?

The OpenAI API provides access to advanced AI models that can generate text, write code, summarize content, analyze images (supported models), and perform many other AI tasks.

Applications include:

- Chatbots
- AI Assistants
- Content Generation
- Code Generation
- Customer Support
- Document Summarization

---

# Steps to Use OpenAI API

1. Create an OpenAI account.
2. Generate an API key.
3. Install the OpenAI SDK.
4. Send a request to the API.
5. Receive and display the response.

---

# Example (Node.js)

```javascript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.OPENAI_API_KEY,
});

const response = await client.responses.create({
  model: "gpt-4.1-mini",
  input: "Explain REST API in simple English."
});

console.log(response.output_text);
```

---

# API Key

An API Key is a secret key used to authenticate requests.

Example:

```
OPENAI_API_KEY=your_api_key
```

Store API keys in environment variables.

Never hard-code API keys in source code.

# Gemini API

## What is the Gemini API?

The Gemini API provides access to Google's Gemini AI models.

It can perform tasks such as:

- Text generation
- Code generation
- Summarization
- Translation
- Question answering
- Multimodal tasks (supported models)

---

# Steps to Use Gemini API

1. Get an API key.
2. Install the Gemini SDK.
3. Send a prompt to the model.
4. Receive the response.

---

# Example (Node.js)

```javascript
import { GoogleGenAI } from "@google/genai";

const ai = new GoogleGenAI({
  apiKey: process.env.GEMINI_API_KEY,
});

const response = await ai.models.generateContent({
  model: "gemini-2.5-flash",
  contents: "Explain Docker in simple English."
});

console.log(response.text);
```

---

# OpenAI API vs Gemini API

| OpenAI API | Gemini API |
|------------|------------|
| Developed by OpenAI | Developed by Google |
| Access to GPT models | Access to Gemini models |
| Supports text, code, images (supported models) | Supports text, code, and multimodal tasks (supported models) |
| Used for chatbots and AI assistants | Used for chatbots, assistants, and productivity applications |

# What is an SDK?

SDK stands for **Software Development Kit**.

An SDK is a collection of tools and libraries that makes it easier to use an API.

Benefits:

- Less code
- Easier integration
- Better error handling
- Faster development

# Error Handling

Common errors when using AI APIs:

- Invalid API Key
- Network Error
- Rate Limit Exceeded
- Invalid Request
- Server Error

Example:

```javascript
try {
  // API Request
} catch (error) {
  console.log(error.message);
}
```

# Best Practices

- Store API keys in environment variables.
- Never expose API keys to users.
- Validate user input before sending requests.
- Handle API errors gracefully.
- Use appropriate AI models for the task.
- Limit unnecessary API calls to reduce cost.
- Monitor API usage and rate limits.
