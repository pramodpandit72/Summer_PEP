# resumes/

Place your PDF resume files here for testing the AI Resume Screener.

## Sample Usage

Upload any PDF resumes through the Streamlit UI at:
```
http://localhost:8501
```

## Tips
- Resumes should be text-based PDFs (not scanned images)
- The system works best with clearly structured resumes
- Skills like Python, Java, Machine Learning, Docker, etc. are auto-detected
