# 1. Complexity Analysis

## What is Complexity Analysis?

Complexity Analysis tells us **how efficient an algorithm is**.

We mainly measure two things:

- Time Complexity
- Space Complexity

Instead of measuring actual execution time (which depends on computer speed), we measure **how the running time grows as input size (N) increases**.

Example:

```cpp
for(int i=0;i<n;i++)
    cout<<i;
```

If `n = 10`, loop runs 10 times.

If `n = 1000`, loop runs 1000 times.

Time grows proportional to `n`.

So,

**Time Complexity = O(N)**

---

# Why Do We Need Complexity Analysis?

Suppose two algorithms solve the same problem.

Algorithm A:

```cpp
for(int i=0;i<n;i++)
```

Algorithm B:

```cpp
for(int i=0;i<n*n;i++)
```

For

```
n = 1000
```

Algorithm A

```
1000 operations
```

Algorithm B

```
10,00,000 operations
```

Obviously Algorithm A is much faster.

Complexity helps us compare algorithms.

---

# Time Complexity

Time Complexity represents the number of operations performed with respect to input size.

We use **Big O Notation**.

---

## Common Time Complexities

| Complexity | Name | Performance |
|------------|------|-------------|
| O(1) | Constant | Excellent |
| O(log N) | Logarithmic | Excellent |
| O(N) | Linear | Good |
| O(N log N) | Linearithmic | Very Good |
| O(N²) | Quadratic | Slow |
| O(N³) | Cubic | Very Slow |
| O(2^N) | Exponential | Extremely Slow |
| O(N!) | Factorial | Worst |

---

## O(1)

Number of operations never changes.

Example

```cpp
int x = arr[5];
```

Only one operation.

---

## O(log N)

Input reduces by half every iteration.

Example

```cpp
while(n>1)
{
    n/=2;
}
```

or

Binary Search

Example

```
1024

512

256

128

64

32

16

8

4

2

1
```

Only 10 steps.

---

## O(N)

One loop.

```cpp
for(int i=0;i<n;i++)
```

---

## O(N log N)

Usually appears in

- Merge Sort
- Heap Sort
- Quick Sort (Average)
- STL sort()

---

## O(N²)

Nested loops.

```cpp
for(...)
    for(...)
```

Example

Bubble Sort

Selection Sort

Insertion Sort (Worst Case)

---

## O(2^N)

Recursion generates two recursive calls.

Example

Fibonacci

```cpp
f(n)=f(n-1)+f(n-2)
```

---

## O(N!)

Generating all permutations.

# Rules for Calculating Complexity

## Rule 1

Sequential statements

```cpp
a++;
b++;
c++;
```

Complexity

```
O(1)
```

---

## Rule 2

Single Loop

```cpp
for(...)
```

```
O(N)
```

---

## Rule 3

Nested Loops

```cpp
for(...)
    for(...)
```

```
O(N²)
```

---

## Rule 4

Consecutive Loops

```cpp
for(...)
for(...)
```

```
O(N)
```

NOT

```
O(2N)
```

Ignore constants.

---

## Rule 5

Drop Constants

```
O(2N)

O(100N)

O(500N)
```

All become

```
O(N)
```

---

## Rule 6

Keep Highest Order Term

```
O(N² + N + 100)
```

becomes

```
O(N²)
```

|---|---------------------|
