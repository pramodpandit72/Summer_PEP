# 1. Introduction to Graphs

## What is a Graph?

A Graph is a **non-linear data structure** consisting of

- Vertices (Nodes)
- Edges (Connections)

Unlike Trees, Graphs

- Can contain cycles
- Can have multiple paths
- May not be connected

---

Example

```
    0 ----- 1
    |     / |
    |   /   |
    | /     |
    2 ----- 3
```

Vertices

```
0 1 2 3
```

Edges

```
0-1

1-2

2-3

0-2

1-3
```

---

# Applications

Graphs are used in

- Social Networks
- Google Maps
- Flight Networks
- Computer Networks
- Web Pages
- Recommendation Systems
- Dependency Graphs

# 2. Graph Terminology

## Vertex

A node in a graph.

---

## Edge

Connection between two vertices.

---

## Adjacent Vertices

Two vertices connected by an edge.

---

## Degree

Number of edges connected to a vertex.

Example

```
0 -- 1 -- 2
```

Degree

```
1 = 2
```

---

## Path

Sequence of vertices connected by edges.

Example

```
0 → 1 → 3
```

---

## Cycle

A path that starts and ends at the same vertex.

Example

```
0 → 1 → 2 → 0
```

---

## Connected Graph

Every node is reachable from every other node.

---

## Disconnected Graph

Contains two or more separate groups of nodes.

Example

```
0---1

2---3
```

# 4. Graph Representation

Two common methods.

---

## Adjacency Matrix

```
    0 1 2

0   0 1 1

1   1 0 1

2   1 1 0
```

Space

```
O(V²)
```

Good for dense graphs.

---

## Adjacency List (Most Used)

Example

```
0 → 1 2

1 → 0 2

2 → 0 1
```

C++ Representation

```cpp
vector<vector<int>> graph(n);
```

Adding an edge

```cpp
graph[u].push_back(v);
graph[v].push_back(u); // Undirected Graph
```

Space

```
O(V + E)
```

Preferred in interviews.

# 5. Breadth First Search (BFS)

## What is BFS?

BFS visits nodes **level by level**.

Uses a

```
Queue
```

---

Example

```
      0
    / | \
   1  2  3
      |
      4
```

Starting from

```
0
```

Traversal

```
0 1 2 3 4
```

---

## BFS Algorithm

1. Push source node into queue.
2. Mark it visited.
3. Pop front node.
4. Visit all unvisited neighbors.
5. Repeat until queue becomes empty.

---

## BFS Code

```cpp
void bfs(int start, vector<vector<int>>& graph)
{
    int n = graph.size();

    vector<bool> visited(n, false);

    queue<int> q;

    q.push(start);

    visited[start] = true;

    while(!q.empty())
    {
        int node = q.front();

        q.pop();

        cout << node << " ";

        for(int neighbor : graph[node])
        {
            if(!visited[neighbor])
            {
                visited[neighbor] = true;
                q.push(neighbor);
            }
        }
    }
}
```

---

## Complexity

Time

```
O(V + E)
```

Space

```
O(V)
```

---

# Applications of BFS

- Shortest Path in Unweighted Graph
- Level Order Traversal
- Connected Components
- Bipartite Graph
- Minimum Steps Problems

# 6. Depth First Search (DFS)

## What is DFS?

DFS explores as deep as possible before backtracking.

Uses

- Recursion
- Stack

---

Example

```
      0
    / | \
   1  2  3
      |
      4
```

Possible DFS

```
0 1 2 4 3
```

Traversal order may vary.

---

## Recursive DFS

```cpp
void dfs(int node, vector<vector<int>>& graph, vector<bool>& visited)
{
    visited[node] = true;

    cout << node << " ";

    for(int neighbor : graph[node])
    {
        if(!visited[neighbor])
            dfs(neighbor, graph, visited);
    }
}
```

---

## DFS Complexity

Time

```
O(V + E)
```

Space

```
O(V)
```

(Recursion stack + visited array)

---

# BFS vs DFS

| Feature | BFS | DFS |
|----------|-----|-----|
| Uses | Queue | Stack / Recursion |
| Traversal | Level-wise | Depth-wise |
| Shortest Path (Unweighted) | Yes | No |
| Memory | More | Usually Less |
| Common Use | Minimum Distance | Backtracking |

---

# Applications of DFS

- Connected Components
- Cycle Detection
- Topological Sort
- Bridges
- Articulation Points
- Tree Traversals

# 7. Connected Components

## What is a Connected Component?

A Connected Component is a group of vertices where every vertex is reachable from every other vertex.

---

Example

```
0 --- 1

2 --- 3 --- 4

5
```

Components

```
{0,1}

{2,3,4}

{5}
```

Total

```
3
```

---

## Algorithm

1. Create a visited array.
2. Traverse all vertices.
3. If a node is unvisited,
   - Start BFS/DFS.
   - Mark all reachable nodes.
   - Increment answer.

---

## DFS Code

```cpp
void dfs(int node,
         vector<vector<int>>& graph,
         vector<bool>& visited)
{
    visited[node] = true;

    for(int next : graph[node])
    {
        if(!visited[next])
            dfs(next, graph, visited);
    }
}

int countComponents(vector<vector<int>>& graph)
{
    int n = graph.size();

    vector<bool> visited(n,false);

    int components = 0;

    for(int i=0;i<n;i++)
    {
        if(!visited[i])
        {
            dfs(i,graph,visited);
            components++;
        }
    }

    return components;
}
```

---

Complexity

```
O(V + E)
```

# 9. Common Mistakes

## Forgetting Visited Array

Leads to

```
Infinite Loop
```

---

## Marking Visited Too Late

Correct

```cpp
visited[next] = true;

q.push(next);
```

Not after popping.

---

## Wrong Graph Representation

For an Undirected Graph

```cpp
graph[u].push_back(v);

graph[v].push_back(u);
```

---

## Forgetting Disconnected Components

Always traverse every node if the graph may be disconnected.

---

## Stack Overflow

Recursive DFS may overflow on very deep graphs.

Use iterative DFS if necessary.
