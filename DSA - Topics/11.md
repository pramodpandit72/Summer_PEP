# 1. Introduction to Shortest Path

## What is a Shortest Path?

A shortest path is the path between two vertices with the **minimum total cost (distance)**.

Example

```
        2
   A -------- B
   |          |
 5 |          | 1
   |          |
   C -------- D
        2
```

Shortest path

```
A → B → D

Cost = 3
```

---

# Applications

Shortest path algorithms are used in

- Google Maps
- GPS Navigation
- Flight Networks
- Internet Routing
- Network Optimization
- Games
- Robotics

# 3. BFS vs Dijkstra

Suppose

```
0 --10-- 1

 \

  1

   \

    2 --1-- 1
```

BFS chooses

```
0 → 1
```

because it has fewer edges.

Cost

```
10
```

Correct shortest path

```
0 → 2 → 1

Cost = 2
```

Hence

**BFS fails on weighted graphs.**

---

Comparison

| Feature | BFS | Dijkstra |
|----------|-----|-----------|
| Graph | Unweighted | Positive Weights |
| Data Structure | Queue | Min Heap |
| Shortest Path | Yes | Yes |
| Time | O(V+E) | O((V+E)logV) |

# 4. Dijkstra's Algorithm

## Idea

Always process the node with the **smallest known distance**.

Uses

```
Min Heap
```

---

Example

```
      4

0 -------- 1

|          |

2          1

|          |

2 -------- 3
      3
```

Source

```
0
```

Distances

```
0 = 0

2 = 2

1 = 4

3 = 5
```

---

## Steps

1. Initialize all distances to Infinity.
2. Distance of source = 0.
3. Push source into Min Heap.
4. Pop the node with minimum distance.
5. Relax all adjacent edges.
6. Update distance if a shorter path is found.
7. Repeat until heap becomes empty.

---

# Relaxation

Suppose

```
Current Distance to u

=

5
```

Edge

```
u → v

Weight = 3
```

Current distance to

```
v = 12
```

New distance

```
5 + 3 = 8
```

Since

```
8 < 12
```

Update

```
dist[v] = 8
```

This is called **Relaxation**.

In C++

```cpp
priority_queue<
pair<int,int>,

> pq;
```

Store

```
(distance, node)
```

Top of heap

```
Smallest Distance
```

---

# 6. Dijkstra Implementation

```cpp
vector<int> dijkstra(
int n,
vector<vector<pair<int,int>>>& graph,
int source)
{
    vector<int> dist(n, INT_MAX);

    priority_queue<
    pair<int,int>,
    vector<pair<int,int>>,
    greater<pair<int,int>>
    > pq;

    dist[source] = 0;

    pq.push({0, source});

    while(!pq.empty())
    {
        auto [d, node] = pq.top();

        pq.pop();

        if(d > dist[node])
            continue;

        for(auto [next, weight] : graph[node])
        {
            if(dist[node] + weight < dist[next])
            {
                dist[next] = dist[node] + weight;

                pq.push({dist[next], next});
            }
        }
    }

    return dist;
}
```

---

## Complexity

Using Binary Heap

Time

```
O((V + E) log V)
```

Space

```
O(V)
```

---

# Why Check?

```cpp
if(d > dist[node])
    continue;
```

Because the heap may contain **outdated entries**.

Skipping them improves efficiency.

# 7. Path Reconstruction

Sometimes we need the actual shortest path.

Maintain

```cpp
parent[node]
```

Whenever distance improves

```cpp
parent[next] = node;
```

Example

```
Destination

↓

6

↓

4

↓

2

↓

0
```

Reverse

```
0 → 2 → 4 → 6
```


# 8. Common Mistakes

## Using BFS on Weighted Graphs

Wrong.

Use

```
Dijkstra
```

---

## Forgetting Min Heap

Default Priority Queue in C++

is a

```
Max Heap
```

Use

```cpp
greater<pair<int,int>>
```

---

## Not Skipping Outdated Entries

Always write

```cpp
if(d > dist[node])
    continue;
```

---

## Integer Overflow

When

```cpp
dist[node] == INT_MAX
```

avoid adding weights directly.

---

## Using Dijkstra for Negative Edges

Never use Dijkstra when edge weights can be negative.
