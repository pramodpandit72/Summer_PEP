# 1. Introduction to MST

## What is a Minimum Spanning Tree?

A **Minimum Spanning Tree (MST)** is a subset of edges in a **connected, weighted, undirected graph** that:

- Connects all vertices.
- Contains **no cycles**.
- Has the **minimum possible total edge weight**.

---

Example

```
      4
 A -------- B
 | \        |
2|  \5      |3
 |    \     |
 C------D
     1
```

Possible MST

```
A -- C (2)

C -- D (1)

D -- B (3)

Total Cost = 6
```

---

# Applications of MST

- Road Network Design
- Electrical Wiring
- Water Pipelines
- Computer Networks
- Cable TV Networks
- Clustering (Machine Learning)

---

# 2. Spanning Tree

A **Spanning Tree** is a tree that

- Includes every vertex.
- Has exactly

```
V - 1
```

edges.
- Contains **no cycles**.

---

Properties

For a graph with

```
V
```

vertices,

MST always has

```
V - 1
```

edges.

---

# Conditions for MST

The graph must be

- Connected
- Undirected
- Weighted

If the graph is disconnected,

we get a **Minimum Spanning Forest**.

---

# 4. Prim's Algorithm (Introduction)

## Idea

Start from any node.

Repeatedly choose the **minimum weight edge** that connects a visited node to an unvisited node.

Uses

```
Min Heap (Priority Queue)
```

---

Steps

1. Start from any node.
2. Push all adjacent edges.
3. Pick minimum edge.
4. Ignore if destination already visited.
5. Repeat until all vertices are visited.

---

Complexity

Using Priority Queue

```
O((V + E) log V)
```

---

# 5. Kruskal's Algorithm

## Idea

Sort all edges by weight.

Pick the smallest edge.

If it creates a cycle,

```
Skip
```

Otherwise,

```
Take it
```

To detect cycles efficiently,

use

```
DSU (Union Find)
```

---

Algorithm

1. Sort edges.
2. Initially every node is separate.
3. Traverse edges.
4. If endpoints belong to different sets,
   - Add edge to MST.
   - Union the sets.
5. Otherwise ignore the edge.

---

Complexity

Sorting

```
O(E log E)
```

DSU Operations

Almost

```
O(1)
```

Overall

```
O(E log E)
```

---

# Example

Edges

```
1-2 = 1

2-3 = 2

1-3 = 4

3-4 = 5
```

Sorted

```
1

2

4

5
```

Choose

```
1-2

2-3

Skip 1-3 (Cycle)

3-4
```

# 6. Disjoint Set Union (DSU)

Also called

- Union Find
- Disjoint Set

---

## What is DSU?

A data structure used to efficiently maintain groups (sets) of connected elements.

Supports two operations

- Find
- Union

---

Initially

```
1

2

3

4
```

Every node is its own parent.

---

# Parent Array

```cpp
parent[i] = i;
```

Meaning

Each node is its own set.

---

# Find Operation

Returns the **representative (root)** of a set.

Example

```
1

↓

2

↓

3
```

Find

```
find(1)

↓

3
```

---

# Union Operation

Merge two different sets.

Example

Before

```
1

2
```

After

```
1

↓

2
```

---

# Basic DSU Code

```cpp
class DSU
{
public:

    vector<int> parent;

    DSU(int n)
    {
        parent.resize(n);

        for(int i=0;i<n;i++)
            parent[i]=i;
    }

    int find(int x)
    {
        if(parent[x]==x)
            return x;

        return find(parent[x]);
    }

    void unite(int x,int y)
    {
        int px=find(x);

        int py=find(y);

        if(px!=py)
            parent[px]=py;
    }
};
```

# 7. Union by Rank & Union by Size

Without optimization,

the DSU tree can become tall.

Example

```
1

↓

2

↓

3

↓

4

↓

5
```

Find becomes slow.

---

## Union by Rank

Attach the smaller height tree under the taller tree.

Maintain

```cpp
rank[]
```

---

## Union by Size

Attach the smaller set under the larger set.

Maintain

```cpp
size[]
```

Both reduce tree height.

---

# Union by Size Code

```cpp
vector<int> parent, size;

void unite(int u,int v)
{
    u=find(u);
    v=find(v);

    if(u==v)
        return;

    if(size[u] < size[v])
        swap(u,v);

    parent[v]=u;

    size[u]+=size[v];
}
```

# 8. Path Compression

## Idea

Whenever Find is called,

directly connect every node to the root.

Before

```
1

↓

2

↓

3

↓

4
```

After

```
    4
   /|\
  1 2 3
```

Much faster.

---

## Code

```cpp
int find(int x)
{
    if(parent[x]==x)
        return x;

    return parent[x]=find(parent[x]);
}
```

This is one of the **most important interview snippets**.

---

# Optimized DSU

Using

- Path Compression
- Union by Rank/Size

Complexity

```
Almost O(1)

≈ O(α(N))
```

where

```
α(N)
```

is the Inverse Ackermann Function (grows extremely slowly).

# 10. Common Mistakes

## Forgetting Path Compression

Leads to slower Find operations.

---

## Forgetting Union by Rank/Size

Trees become tall.

---

## Union Without Find

Wrong

```cpp
parent[x]=y;
```

Correct

```cpp
parent[find(x)] = find(y);
```

---

## Using Kruskal Without Sorting

Edges **must** be processed in increasing order.

---

## Applying MST on Directed Graphs

MST is defined only for **undirected graphs**.
