# 1. Directed Acyclic Graph (DAG)

## What is a DAG?

A **Directed Acyclic Graph (DAG)** is a graph that:

- Is **Directed**
- Has **No Cycles**

Example

```
0 → 1 → 3
↓   ↓
2 → 4
```

This is a DAG because there is **no path that returns to the starting node**.

---

## Why are DAGs Important?

Many real-world problems naturally form DAGs.

Examples

- Course prerequisites
- Build systems (Compilers)
- Task scheduling
- Project planning
- Package dependency management

---

# 2. Topological Sort

## What is Topological Sort?

A **Topological Sort** is an ordering of vertices such that

For every directed edge

```
u → v
```

vertex

```
u
```

appears before

```
v
```

---

Example

Graph

```
5 → 2

5 → 0

4 → 0

4 → 1

2 → 3

3 → 1
```

One valid ordering

```
5 4 2 3 1 0
```

Another valid ordering

```
4 5 2 3 0 1
```

Multiple answers are possible.

---

## Important Property

Topological Sort exists **only for DAGs**.

If the graph contains a cycle,

Topological Sort is **not possible**.

# 3. Kahn's Algorithm (BFS)

## Idea

Repeatedly remove nodes with

```
Indegree = 0
```

Uses

```
Queue
```

---

## What is Indegree?

Indegree = Number of incoming edges.

Example

```
0 → 1 ← 2
```

Indegree

```
0 = 0

1 = 2

2 = 0
```

---

## Algorithm

1. Compute indegree of every node.
2. Push all nodes with indegree 0 into a queue.
3. Remove a node from the queue.
4. Add it to the answer.
5. Reduce indegree of all neighbors.
6. If a neighbor's indegree becomes 0, push it into the queue.
7. Repeat until the queue is empty.

---

## Kahn's Algorithm Code

```cpp
vector<int> topoSort(int n, vector<vector<int>>& graph)
{
    vector<int> indegree(n, 0);

    for(int u = 0; u < n; u++)
    {
        for(int v : graph[u])
            indegree[v]++;
    }

    queue<int> q;

    for(int i = 0; i < n; i++)
    {
        if(indegree[i] == 0)
            q.push(i);
    }

    vector<int> order;

    while(!q.empty())
    {
        int node = q.front();
        q.pop();

        order.push_back(node);

        for(int next : graph[node])
        {
            indegree[next]--;

            if(indegree[next] == 0)
                q.push(next);
        }
    }

    return order;
}
```

---

## Complexity

Time

```
O(V + E)
```

Space

```
O(V)
```

---

## Cycle Detection Using Kahn's Algorithm

If

```
Topological Order Size < Number of Vertices
```

then

```
Cycle Exists
```

# 4. DFS-Based Topological Sort

## Idea

Visit every node using DFS.

After exploring all neighbors,

push the node into a stack.

Finally,

reverse the stack (or pop from it).

---

## Code

```cpp
void dfs(int node,
         vector<vector<int>>& graph,
         vector<bool>& visited,
         stack<int>& st)
{
    visited[node] = true;

    for(int next : graph[node])
    {
        if(!visited[next])
            dfs(next, graph, visited, st);
    }

    st.push(node);
}
```

---

Driver

```cpp
vector<int> topoSort(int n, vector<vector<int>>& graph)
{
    vector<bool> visited(n, false);

    stack<int> st;

    for(int i = 0; i < n; i++)
    {
        if(!visited[i])
            dfs(i, graph, visited, st);
    }

    vector<int> order;

    while(!st.empty())
    {
        order.push_back(st.top());
        st.pop();
    }

    return order;
}
```

---

## Complexity

Time

```
O(V + E)
```

Space

```
O(V)
```

---

# Kahn vs DFS Topological Sort

| Feature | Kahn | DFS |
|----------|------|-----|
| Uses | Queue | Stack / Recursion |
| Based On | Indegree | DFS Finish Time |
| Detect Cycle | Yes | Needs extra logic |
| Complexity | O(V+E) | O(V+E) |

# 5. Strongly Connected Components (SCC)

## What is an SCC?

A **Strongly Connected Component** is a group of vertices in a **directed graph** where

Every vertex is reachable from every other vertex.

---

Example

```
0 → 1
↑   ↓
3 ← 2

4 → 5
```

SCCs

```
{0,1,2,3}

{4}

{5}
```

---

## Difference Between Connected Component and SCC

| Connected Component | SCC |
|---------------------|-----|
| Undirected Graph | Directed Graph |
| Reachability in one direction is enough | Reachability must exist in both directions |

---

# 6. Kosaraju's Algorithm (Introduction)

Kosaraju's Algorithm finds all SCCs.

---

## Steps

### Step 1

Perform DFS and store nodes in a stack according to finishing time.

---

### Step 2

Reverse all graph edges.

Original

```
A → B
```

Reversed

```
A ← B
```

---

### Step 3

Pop nodes from the stack.

Run DFS on the reversed graph.

Each DFS gives **one SCC**.

---

## Complexity

Time

```
O(V + E)
```

Space

```
O(V + E)
```

---

# Why Reverse the Graph?

Reversing the graph ensures that each DFS started from the finishing-time order discovers exactly one SCC before moving to another.

---

# 7. Tarjan's Algorithm (Overview)

Tarjan's Algorithm is another method to find SCCs.

Uses

- DFS
- Discovery Time
- Low Link Values
- Stack

---

## Complexity

Time

```
O(V + E)
```

Space

```
O(V)
```

---

## Kosaraju vs Tarjan

| Feature | Kosaraju | Tarjan |
|----------|----------|---------|
| DFS Passes | 2 | 1 |
| Reverse Graph | Required | Not Required |
| Simplicity | Easier | More Advanced |

For interviews, Kosaraju is usually easier to explain.

# 9. Common Mistakes

## Applying Topological Sort on Undirected Graphs

Topological Sort is only defined for **Directed Graphs**.

---

## Forgetting Indegree Calculation

Kahn's Algorithm depends on correct indegree values.

---

## Assuming a Unique Topological Order

Multiple valid orders may exist.

---

## Forgetting to Reverse the Graph in Kosaraju

Without reversing, SCC detection is incorrect.

---

## Ignoring Cycles

A graph with cycles **cannot** have a valid topological ordering.
