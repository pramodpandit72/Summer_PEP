# 2. Knapsack Pattern

One of the most important DP patterns.

---

## 0/1 Knapsack

Each item can be chosen **at most once**.

Choices

```
Pick

or

Not Pick
```

State

```
dp[i][w]

=

Maximum value

using first i items

with capacity w
```

Transition

```
dp[i][w]

=

max(

notPick,

pick

)
```

---

## Time Complexity

```
O(N × W)
```

---

## Common Problems

- 0/1 Knapsack
- Partition Equal Subset Sum
- Target Sum
- Last Stone Weight II

---

## Unbounded Knapsack

Items can be picked **multiple times**.

Examples

- Coin Change
- Rod Cutting
- Perfect Squares

---

# 3. Subsequence DP

State depends on **two sequences**.

Usually

```
dp[i][j]
```

Meaning

Answer using

```
First i characters

First j characters
```

---

Common problems

- LCS
- Edit Distance
- Distinct Subsequences
- Shortest Common Supersequence

# 4. Longest Common Subsequence (LCS)

Example

```
ABCDEF

AEDFHR
```

LCS

```
ADF
```

Length

```
3
```

---

State

```
dp[i][j]

=

LCS length

between

text1[0...i-1]

text2[0...j-1]
```

---

Transition

If characters match

```
dp[i][j]

=

1 + dp[i-1][j-1]
```

Else

```
max(

dp[i-1][j],

dp[i][j-1]

)
```

---

Complexity

Time

```
O(N × M)
```

Space

```
O(N × M)
```

Can be optimized to

```
O(M)
```

---

Applications

- Version Control (Git)
- DNA Matching
- Spell Check
- Diff Tools

---

# 5. Longest Increasing Subsequence (LIS)

Example

```
10 9 2 5 3 7 101 18
```

LIS

```
2 3 7 101
```

Length

```
4
```

---

## DP Solution

State

```
dp[i]

=

Longest LIS ending at i
```

Transition

```
if(nums[j] < nums[i])

dp[i]

=

max(

dp[i],

dp[j]+1

)
```

---

Complexity

```
O(N²)
```

---

## Optimized LIS

Using

```
Binary Search
```

Complexity

```
O(N log N)
```

Very popular interview question.

---

Applications

- Scheduling
- Stock Analysis
- Sequence Optimization

---

# 6. Interval DP

State

```
dp[l][r]
```

Meaning

Answer for

```
Subarray

l...r
```

---

Common Problems

- Burst Balloons
- Matrix Chain Multiplication
- Minimum Cost Tree From Leaf Values
- Palindrome Partitioning

---

Example

```
Burst Balloons
```

Choose the last balloon to burst inside an interval.

---

Complexity

Usually

```
O(N³)
```

---

# 7. Bitmask DP (Introduction)

Used when

```
N ≤ 20
```

Represent a subset using bits.

Example

```
N = 4

Mask

1010
```

Means

Elements

```
1

3
```

are selected.

---

Applications

- Traveling Salesman
- Assignment Problem
- Hamiltonian Path

---

Complexity

Usually

```
O(2^N × N)
```

---

# 8. Digit DP (Introduction)

Used for problems like

```
Count numbers

from L to R

satisfying some condition.
```

Examples

- No repeated digits
- Sum of digits
- Count even digit sum
- Digit restrictions

---

State usually contains

```
Position

Tight

Leading Zero

Other constraints
```

---

Mostly used in

Competitive Programming.

---

# 9. Tree DP (Introduction)

Dynamic Programming on Trees.

Solve children first,

then compute the parent.

---

Example

House Robber III

Choice

```
Rob Node

or

Skip Node
```

---

Applications

- Diameter
- Tree Matching
- Independent Set
- Maximum Path Sum

# 10. DP Optimization Ideas

---

## Space Optimization

Instead of

```
dp[n]
```

use

```
Previous States
```

---

## Binary Search Optimization

Used in

```
LIS

O(N log N)
```

---

## Prefix Sum Optimization

Often used to reduce transition cost.

---

## Monotonic Queue Optimization

Useful in

Sliding Window DP.

---

## Divide and Conquer DP

Advanced optimization for specific recurrences.

Mostly for Competitive Programming.

---

# How to Identify DP Pattern

| Clue in Problem | DP Pattern |
|-----------------|------------|
| Pick / Not Pick | Knapsack |
| Two Strings | LCS |
| Increasing Sequence | LIS |
| Subarray / Interval | Interval DP |
| Tree | Tree DP |
| Subsets | Bitmask DP |
| Digits | Digit DP |

# 11. Common Mistakes

## Wrong State Definition

The state should uniquely identify a subproblem.

---

## Incorrect Transition

Always verify all possible choices.

---

## Forgetting Base Cases

Many WA errors come from incorrect initialization.

---

## Choosing Wrong DP Pattern

Identify the pattern before coding.

---

## Ignoring Space Optimization

Can reduce memory from

```
O(N²)

↓

O(N)
```
