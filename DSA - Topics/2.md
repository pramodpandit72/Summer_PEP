# 1. Advanced Arrays

## What is an Array?

An array is a collection of elements stored in **contiguous memory locations**.

Example

```cpp
int arr[] = {5, 2, 8, 10, 7};
```

Memory Representation

```
Index : 0   1   2   3   4
Value : 5   2   8  10   7
```

### Advantages

- O(1) Random Access
- Cache Friendly
- Easy Traversal

### Disadvantages

- Fixed Size
- Costly Insertions and Deletions

---

```cpp
for(int i = 0; i < n; i++)
```

Time Complexity

```
O(N)
```

```cpp
cout << arr[3];
```

# 2. Prefix Sum

## What is Prefix Sum?

Prefix Sum stores the cumulative sum from the beginning.

Instead of calculating sum repeatedly, we preprocess once.

---

## Construction

Array

```
2 4 1 6 3
```

Prefix

```
2 6 7 13 16
```

Formula

```
prefix[i] = prefix[i-1] + arr[i]
```

---

## Code

```cpp
vector<int> prefix(n);

prefix[0] = arr[0];

for(int i = 1; i < n; i++)
    prefix[i] = prefix[i-1] + arr[i];
```

Complexity

```
O(N)
```

---

## Range Sum Query

Find sum from L to R.

Formula

```
prefix[R] - prefix[L-1]
```

If

```
L = 0
```

Answer

```
prefix[R]
```

---

Example

Array

```
3 2 5 1 6
```

Prefix

```
3 5 10 11 17
```

Find

```
Sum(1,3)
```

Answer

```
11 - 3 = 8
```

---

# Applications of Prefix Sum

- Range Sum Query
- Count Frequency
- Equilibrium Index
- Subarray Sum
- Difference Array
- 2D Prefix Sum

# 3. Suffix Sum

## What is Suffix Sum?

Stores cumulative sum from the end.

Example

Array

```
2 4 1 6 3
```

Suffix

```
16 14 10 9 3
```

Formula

```
suffix[i] = suffix[i+1] + arr[i]
```

---

## Code

```cpp
vector<int> suffix(n);

suffix[n-1] = arr[n-1];

for(int i = n-2; i >= 0; i--)
    suffix[i] = suffix[i+1] + arr[i];
```

---

## Applications

- Partition Problems
- Left-Right Sum Comparison
- Equilibrium Index
- Prefix + Suffix Combination Problems

---

# 4. Difference Array

Useful when multiple range updates are required.

Instead of updating every element,

Update only boundaries.

Example

Add 5 from index 2 to 5.

```
diff[2]+=5

diff[6]-=5
```

After all updates,

Take Prefix Sum.

Complexity

```
Range Update : O(1)

Final Build : O(N)
```

# 5. Sliding Window

## What is Sliding Window?

Sliding Window converts

```
O(N²)
```

into

```
O(N)
```

for many subarray problems.

---

Example

Find maximum sum of subarray of size K.

Naive

```
Check every subarray.

O(N²)
```

Sliding Window

```
O(N)
```

---

## Fixed Size Sliding Window

Example

```
K = 3

1 4 2 10 5
```

Window

```
1 4 2

↓

4 2 10

↓

2 10 5
```

---

## Algorithm

Step 1

Take first window sum.

Step 2

Remove left element.

Step 3

Add next element.

Repeat.

---

## Code

```cpp
int sum = 0;

for(int i=0;i<k;i++)
    sum += arr[i];

int ans = sum;

for(int i=k;i<n;i++)
{
    sum += arr[i];
    sum -= arr[i-k];

    ans = max(ans,sum);
}
```

Complexity

```
O(N)
```

---

# Variable Size Sliding Window

Window size changes dynamically.

Example Problems

- Longest Substring Without Repeating Characters
- Minimum Size Subarray Sum
- Fruit Into Baskets
- Max Consecutive Ones III

General Pattern

```cpp
int left = 0;

for(int right=0; right<n; right++)
{
    // Expand

    while(condition fails)
    {
        // Shrink
        left++;
    }

    // Update answer
}
```

---

# When Sliding Window Works

Sliding Window usually works when problem contains

- Continuous Subarray
- Continuous Substring
- Maximum
- Minimum
- Longest
- Smallest
- Exactly K
- At Most K

---

# When Sliding Window Does NOT Work

- Non-contiguous elements
- Sorting required
- Random selections
- Graph problems

---

# 6. Prefix Sum vs Sliding Window

| Prefix Sum | Sliding Window |
|------------|----------------|
| Range Sum Queries | Continuous Window |
| Static Array | Dynamic Window |
| O(1) Query after preprocessing | O(N) traversal |
| Handles multiple queries | Usually single traversal |

# Tips for Interviews

✅ Prefix Sum is generally used for **range queries**.

✅ Sliding Window is used for **continuous subarrays/substrings**.

✅ Difference Array is useful for **multiple updates**.

✅ If constraints are around **10⁵ or 10⁶**, an O(N²) solution will likely fail.

✅ Always check whether the array is **sorted**, as it may allow Binary Search or Two Pointers.
