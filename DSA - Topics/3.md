# 1. Binary Search Basics

## What is Binary Search?

Binary Search is an algorithm used to search an element efficiently by **repeatedly dividing the search space into two halves**.

It works only when the search space is **sorted** or when the answer space is **monotonic**.

Instead of checking every element like Linear Search, Binary Search removes half of the remaining elements in each step.

---

## Why Binary Search?

Suppose an array has

```
1,000,000 elements
```

Linear Search

```
O(N)
≈ 1,000,000 comparisons
```

Binary Search

```
O(log₂N)

≈ 20 comparisons
```

Huge improvement.

---

## Requirements

Binary Search can be applied when:

- Array is sorted.
- Search space is monotonic (True → False or False → True).
- We can decide whether to move left or right.

---

# Binary Search Algorithm

Array

```
1 3 5 7 9 11 15
```

Search

```
9
```

Process

```
Middle = 7

9 > 7

Discard left half

Remaining

9 11 15

Middle = 11

9 < 11

Discard right half

Remaining

9
```

Found.

---

## Template

```cpp
int left = 0;
int right = n - 1;

while(left <= right)
{
    int mid = left + (right - left) / 2;

    if(arr[mid] == target)
        return mid;

    else if(arr[mid] < target)
        left = mid + 1;

    else
        right = mid - 1;
}

return -1;
```

---

## Why

```cpp
left + (right-left)/2
```

instead of

```cpp
(left+right)/2
```

Because

```
left + right
```

may overflow for very large integers.

---

# Complexity

| Operation | Complexity |
|-----------|------------|
| Search | O(log N) |
| Space | O(1) |

# 4. Lower Bound & Upper Bound

These are among the most frequently asked STL functions.

---

## lower_bound()

Returns iterator pointing to the **first element ≥ target**.

Example

```
Array

1 2 4 4 4 7 9
```

Target

```
4
```

Answer

```
Index = 2
```

Code

```cpp
auto it = lower_bound(v.begin(), v.end(), x);
```

Complexity

```
O(log N)
```

---

## upper_bound()

Returns first element **greater than target**.

Example

```
1 2 4 4 4 7
```

Target

```
4
```

Answer

```
Index = 5
```

Code

```cpp
auto it = upper_bound(v.begin(), v.end(), x);
```

---

## Count Frequency

```cpp
count = upper_bound(...) - lower_bound(...);
```

# 5. Search Space Binary Search

Sometimes we don't search an element.

We search the **answer**.

Example

```
Minimum speed

Minimum capacity

Maximum distance

Minimum days
```

This is called

```
Binary Search on Answer
```

---

## Idea

Suppose answer lies between

```
1 ... 1000
```

Instead of checking every value,

Use Binary Search.

---

Example

```
Can Koko eat bananas with speed = 20?
```

If YES

Try smaller speed.

If NO

Try larger speed.

# 6. Parametric Search

## Definition

Parametric Search is a Binary Search technique where we search for the **optimal value** instead of searching an element.

It requires a function

```
isPossible(x)
```

that returns

```
True

or

False
```

The function must be **monotonic**.

---

## Monotonic Property

Example

```
Speed

1

2

3

4

5

6
```

Possible?

```
F F F T T T
```

Once True starts,

It never becomes False.

Binary Search can be applied.

---

## General Template

```cpp
int low = minimumAnswer;
int high = maximumAnswer;

while(low <= high)
{
    int mid = low + (high-low)/2;

    if(isPossible(mid))
    {
        answer = mid;
        high = mid - 1;
    }
    else
    {
        low = mid + 1;
    }
}
```

---

## Steps

Step 1

Find search space.

Step 2

Write

```cpp
isPossible(mid)
```

Step 3

Binary Search on answer.

# 7. How to Identify Binary Search Problems

If the problem contains words like

- Minimum
- Maximum
- Smallest
- Largest
- First
- Last
- Earliest
- Latest
- Closest

Think Binary Search.

---

Also check

Can I write

```cpp
bool isPossible(int x)
```

If YES,

Binary Search on Answer is likely applicable.

# 8. Common Mistakes

## Mistake 1

Overflow

Wrong

```cpp
mid = (left+right)/2;
```

Correct

```cpp
mid = left + (right-left)/2;
```

---

## Mistake 2

Infinite Loop

Incorrect update of

```
left

right
```

Always ensure search space shrinks.

---

## Mistake 3

Wrong Search Space

Choosing incorrect

```
low

high
```

leads to wrong answers.

---

## Mistake 4

Using Binary Search on Unsorted Array

Not allowed unless searching over answer space.

---

## Mistake 5

Confusing lower_bound and upper_bound

Remember

```
lower_bound

>=
```

```
upper_bound

>
```
