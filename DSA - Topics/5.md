# 1. Introduction to Stack

## What is a Stack?

A Stack is a **Linear Data Structure** that follows the **LIFO (Last In, First Out)** principle.

The last element inserted is the first one removed.

Example

```
Push 10
Push 20
Push 30

Stack

30  <- Top
20
10
```

Pop

```
30
```

Remaining

```
20
10
```

---

## Real Life Examples

- Browser Back Button
- Undo / Redo
- Function Call Stack
- Expression Evaluation
- Parentheses Matching

---

# 6. Monotonic Stack

## What is Monotonic Stack?

A stack where elements remain

- Increasing

or

- Decreasing

throughout the algorithm.

---

## Why Use It?

Instead of checking every previous element

```
O(N²)
```

We solve many problems in

```
O(N)
```

---

# Increasing Monotonic Stack

Top always contains

```
Smaller elements
```

Example

```
2

4

6

8
```

---

# Decreasing Monotonic Stack

Top always contains

```
Larger elements
```

Example

```
9

7

5

2
```

---

# General Template (Next Greater Element)

```cpp
stack<int> st;

for(int i = n - 1; i >= 0; i--)
{
    while(!st.empty() && st.top() <= arr[i])
        st.pop();

    if(st.empty())
        ans[i] = -1;
    else
        ans[i] = st.top();

    st.push(arr[i]);
}
```

Complexity

```
O(N)
```

Each element is pushed and popped at most once.

Think Monotonic Stack if the problem asks for:

- Next Greater Element
- Next Smaller Element

- Previous Smaller Element

- Remove K Digits

- Next
- Previous
- Nearest

- Smaller

# Common Mistakes

## Stack

- Calling `top()` on an empty stack.
- Forgetting to `pop()` after processing.
- Using recursion without considering stack overflow.

---

## Queue

- Calling `front()` on an empty queue.
- Confusing Queue with Priority Queue.
- Forgetting FIFO order.

---

## Monotonic Stack

- Using wrong comparison (`<`, `<=`, `>`, `>=`).
- Traversing in the wrong direction.
- Forgetting to push the current element after popping.
- Storing values instead of indices when indices are required.
