# 1. Introduction to Trees

## What is a Tree?

A Tree is a **non-linear hierarchical data structure** consisting of nodes connected by edges.

Unlike Linked Lists, one node can have multiple children.

Example

```
        1
      /   \
     2     3
    / \   / \
   4   5 6   7
```

---

## Why Trees?

Trees are used to represent hierarchical data.

Examples

- File System
- Organization Chart
- HTML DOM
- Binary Search Tree
- Heap
- Trie

---

# Properties

If a tree has

```
N Nodes
```

then

```
Edges = N - 1
```

There is exactly **one unique path** between any two nodes.

Trees do **not** contain cycles.

# 3. Binary Trees

## Definition

A Binary Tree is a tree in which each node has **at most two children**.

```
Left Child

Right Child
```

Example

```
      10
     /  \
    5   20
```

---

## Tree Node Structure

```cpp
struct TreeNode
{
    int val;
    TreeNode *left;
    TreeNode *right;

    TreeNode(int x)
    {
        val = x;
        left = nullptr;
        right = nullptr;
    }
};
```

---

# Creating Nodes

```cpp
TreeNode* root = new TreeNode(1);

root->left = new TreeNode(2);

root->right = new TreeNode(3);
```

# 4. Types of Binary Trees

---

## Full Binary Tree

Every node has either

```
0

or

2 children.
```

```
      1
     / \
    2   3
```

---

## Complete Binary Tree

All levels are completely filled except possibly the last level.

Last level is filled from left to right.

Used in

```
Heap
```

---

## Perfect Binary Tree

Every level completely filled.

All leaf nodes are at the same level.

Number of nodes

```
2^(h+1)-1
```

---

## Balanced Binary Tree

Difference between left and right subtree heights is at most

```
1
```

Examples

- AVL Tree
- Red Black Tree

---

## Degenerate Tree

Every node has only one child.

Looks like

```
Linked List
```

# 5. Tree Traversals

Traversal means visiting every node exactly once.

There are

- DFS (Depth First Search)
- BFS (Breadth First Search)

---

# DFS Traversals

---

## 1. Preorder

```
Root

Left

Right
```

Memory Trick

```
NLR
```

Example

```
        1
      /   \
     2     3
    / \
   4   5
```

Output

```
1 2 4 5 3
```

---

### Recursive Code

```cpp
void preorder(TreeNode* root)
{
    if(root==nullptr)
        return;

    cout<<root->val<<" ";

    preorder(root->left);

    preorder(root->right);
}
```

---

## 2. Inorder

```
Left

Root

Right
```

Memory Trick

```
LNR
```

Example

```
4 2 5 1 3
```

Important

For a

```
BST

Inorder

=

Sorted Order
```

---

Code

```cpp
void inorder(TreeNode* root)
{
    if(root==nullptr)
        return;

    inorder(root->left);

    cout<<root->val<<" ";

    inorder(root->right);
}
```

---

## 3. Postorder

```
Left

Right

Root
```

Memory Trick

```
LRN
```

Output

```
4 5 2 3 1
```

---

Code

```cpp
void postorder(TreeNode* root)
{
    if(root==nullptr)
        return;

    postorder(root->left);

    postorder(root->right);

    cout<<root->val<<" ";
}
```

---

```

```

Worst Case

```

```

```

```

# 7. Breadth First Search (Level Order)

Visits nodes level by level.

Uses

```
Queue
```

---

Example

```
        1
      /   \
     2     3
    / \     \
   4   5     6
```

Output

```
1

2 3

4 5 6
```

---

### Code

```cpp
vector<vector<int>> levelOrder(TreeNode* root)
{
    vector<vector<int>> ans;

    if(root==nullptr)
        return ans;

    queue<TreeNode*> q;

    q.push(root);

    while(!q.empty())
    {
        int size = q.size();

        vector<int> level;

        while(size--)
        {
            TreeNode* node = q.front();

            q.pop();

            level.push_back(node->val);

            if(node->left)
                q.push(node->left);

            if(node->right)
                q.push(node->right);
        }

        ans.push_back(level);
    }

    return ans;
}
```

---

Complexity

```
Time

O(N)

Space

O(N)
```

# Frequently Used Recursive Template

```cpp
void dfs(TreeNode* root)
{
    if(root==nullptr)
        return;

    // Process Current Node

    dfs(root->left);

    dfs(root->right);
}
```

# 9. Common Mistakes

## Forgetting Base Case

Wrong

```cpp
dfs(root->left);
```

Correct

```cpp
if(root==nullptr)
    return;
```

---

## Confusing Height and Depth

Height

```
Node → Leaf
```

Depth

```
Root → Node
```

---

## Using DFS Instead of BFS

If the question asks

```
Level by Level
```

Always think

```
Queue

BFS
```

---

## Infinite Recursion

Always move towards leaf nodes.

---

## Stack Overflow

Deep recursive trees may cause recursion depth issues.
