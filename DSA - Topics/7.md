# 1. Binary Search Tree (BST)

## What is a Binary Search Tree?

A Binary Search Tree (BST) is a Binary Tree with a special property.

For every node,

```
Left Subtree  <  Root  <  Right Subtree
```

Every left child contains a smaller value.

Every right child contains a larger value.

---

Example

```
          8
        /   \
       3     10
      / \      \
     1   6      14
        / \     /
       4   7   13
```

Notice

```
All nodes left of 8

< 8

All nodes right of 8

> 8
```

---

# Why BST?

Because searching becomes much faster than a normal Binary Tree.

Example

```
Binary Tree Search

O(N)

BST Search

O(log N)
```

(Only if the tree is balanced.)

---

# Tree Node

```cpp
struct TreeNode
{
    int val;
    TreeNode *left;
    TreeNode *right;

    TreeNode(int x)
    {
        val = x;
        left = nullptr;
        right = nullptr;
    }
};
```

# 2. BST Operations

---

## Search

Algorithm

```
If target < node

Go Left

Else

Go Right
```

Code

```cpp
TreeNode* search(TreeNode* root, int target)
{
    while(root)
    {
        if(root->val == target)
            return root;

        if(target < root->val)
            root = root->left;
        else
            root = root->right;
    }

    return nullptr;
}
```

Complexity

| Case | Time |
|------|------|
| Balanced BST | O(log N) |
| Worst (Skewed) | O(N) |

---

## Insert

Rule

```
Smaller → Left

Greater → Right
```

Recursive Code

```cpp
TreeNode* insert(TreeNode* root, int val)
{
    if(root == nullptr)
        return new TreeNode(val);

    if(val < root->val)
        root->left = insert(root->left, val);
    else
        root->right = insert(root->right, val);

    return root;
}
```

---

## Delete

Deletion is the most important BST operation.

There are **3 cases**.

---

### Case 1

Node has **No Child**

Simply delete it.

```
5

↓

NULL
```

---

### Case 2

Node has **One Child**

Replace node with its child.

```
     8

    /

   5

  /

3
```

Delete

```
5
```

Result

```
8

/

3
```

---

### Case 3

Node has **Two Children**

Replace node with

- Inorder Successor (minimum in right subtree)

OR

- Inorder Predecessor (maximum in left subtree)

Then delete that replacement node.

---

# Find Minimum

```cpp
TreeNode* findMin(TreeNode* root)
{
    while(root->left)
        root = root->left;

    return root;
}
```

---

# Complexity

| Operation | Balanced | Worst |
|------------|----------|--------|
| Search | O(log N) | O(N) |
| Insert | O(log N) | O(N) |
| Delete | O(log N) | O(N) |

# 5. AVL Tree

## What is AVL Tree?

AVL Tree is a **Self-Balancing Binary Search Tree**.

It automatically balances itself after insertion and deletion.

---

# Balance Factor

```
Balance Factor

=

Height(Left)

-

Height(Right)
```

Valid

```
-1

0

1
```

If Balance Factor becomes

```
2

or

-2
```

Rotation is performed.

---

# Why AVL?

Guarantees

```
Search

Insert

Delete

=

O(log N)
```

---

# Rotations

There are

## LL Rotation

Single Right Rotation

---

## RR Rotation

Single Left Rotation

---

## LR Rotation

Left Rotation

then

Right Rotation

---

## RL Rotation

Right Rotation

then

Left Rotation

---

Example

LL

Before

```
      30

     /

   20

  /

10
```

After Rotation

```
      20

     /  \

   10   30
```

---

# AVL Complexity

| Operation | Complexity |
|-----------|------------|
| Search | O(log N) |
| Insert | O(log N) |
| Delete | O(log N) |

---

# AVL Advantages

- Always Balanced
- Fast Searching
- Better Lookup than BST

---

# AVL Disadvantages

- Complex Rotations
- More Memory
- Slower Insertion than normal BST

# 6. Segment Tree

## What is Segment Tree?

Segment Tree is a Binary Tree used for **Range Queries**.

Example

Find

```
Sum from index L to R
```

Many times.

---

Without Segment Tree

Each Query

```
O(N)
```

With Segment Tree

```
O(log N)
```

---

# Applications

- Range Sum
- Range Minimum
- Range Maximum
- Range GCD
- Range XOR

---

Example

Array

```
2 5 1 4 9
```

Need

```
Sum(1,4)

Sum(0,3)

Sum(2,2)
```

Many times.

Use

```
Segment Tree
```

---

# Structure

```
               Sum(0-4)

             /          \

       Sum(0-2)      Sum(3-4)

      /      \         /    \

 Sum(0-1)  Sum(2)   Sum(3) Sum(4)
```

Each node stores information about a segment (range) of the array.

---

# Operations

## Build Tree

```
O(N)
```

---

## Query

```
Range Sum

Range Minimum

Range Maximum

O(log N)
```

---

## Update

Change one element.

```
O(log N)
```

---

# Segment Tree Complexity

| Operation | Complexity |
|-----------|------------|
| Build | O(N) |
| Query | O(log N) |
| Update | O(log N) |

---

# Segment Tree vs Prefix Sum

| Prefix Sum | Segment Tree |
|------------|--------------|
| Static Array | Dynamic Array |
| O(1) Query | O(log N) Query |
| Update O(N) | Update O(log N) |

Use Prefix Sum when the array **never changes**.

Use Segment Tree when there are **many updates and queries**.

---

# 7. BST vs AVL vs Segment Tree

| Feature | BST | AVL | Segment Tree |
|----------|-----|-----|--------------|
| Search | O(log N)* | O(log N) | Not for search |
| Insert | O(log N)* | O(log N) | O(log N) (update) |
| Delete | O(log N)* | O(log N) | O(log N) (update) |
| Range Query | Poor | Poor | Excellent |
| Self Balanced | No | Yes | N/A |

\*Only when BST is balanced.

---

# When to Use What?

| Problem | Data Structure |
|----------|----------------|
| Search Sorted Data | BST |
| Fast Search + Frequent Updates | AVL |
| Range Queries | Segment Tree |
| Static Range Sum | Prefix Sum |
| Ordered Set/Map | BST / Balanced BST |

# 8. Common Mistakes

## BST

- Forgetting BST property.
- Incorrect deletion when node has two children.
- Assuming every Binary Tree is a BST.

---

## AVL

- Forgetting to update heights after rotation.
- Using wrong rotation (LL, RR, LR, RL).

---

## Segment Tree

- Incorrect segment boundaries.
- Forgetting to update parent nodes after updates.
- Using Segment Tree when Prefix Sum is sufficient.
