# 1. Introduction to Heap

## What is a Heap?

A Heap is a **Complete Binary Tree** that satisfies the **Heap Property**.

There are two types:

- Max Heap
- Min Heap

Unlike a BST, a Heap **does not maintain sorted order**.

---

## Why Heap?

Heap is mainly used when we need:

- Largest Element
- Smallest Element
- Top K Elements
- Priority Scheduling
- Fast Insert/Delete of Maximum or Minimum

---

# Complete Binary Tree

A Heap is always a **Complete Binary Tree**.

Example

```
          10
        /    \
       8      6
      / \    /
     5   3  2
```

Every level is completely filled except possibly the last level.

The last level is filled from **left to right**.

---

# 2. Binary Heap

A Binary Heap is implemented using an **Array**.

Example

```
Heap

        50
      /    \
     30     20
    /  \
   10  15
```

Array Representation

```
Index

0 1 2 3 4

Value

50 30 20 10 15
```

---

## Parent and Child Formula

If index is

```
i
```

Then

Parent

```cpp
(i-1)/2
```

Left Child

```cpp
2*i+1
```

Right Child

```cpp
2*i+2
```

These formulas are very important for interviews.

---

# 3. Max Heap & Min Heap

## Max Heap

Every parent is greater than or equal to its children.

Example

```
       90
      /  \
    70   60
   / \
 40 20
```

Largest element is always at the root.

---

## Min Heap

Every parent is smaller than or equal to its children.

Example

```
       10
      /  \
    20   30
   / \
 40 50
```

Smallest element is always at the root.

---

# Heap Property

### Max Heap

```
Parent >= Children
```

### Min Heap

```
Parent <= Children
```

# 4. Priority Queue (STL)

A Priority Queue is implemented using a Heap.

---

## Max Heap (Default)

```cpp
priority_queue<int> pq;
```

Example

```cpp
pq.push(5);
pq.push(1);
pq.push(10);

pq.top();
```

Output

```
10
```

---

## Min Heap

```cpp
priority_queue<int, vector<int>, greater<int>> pq;
```

Example

```
Insert

5

1

10
```

Top

```
1
```

# 5. Heap Operations

---

## Insert

Insert at last position.

Move upward until Heap Property is restored.

Called

```
Heapify Up

or

Sift Up
```

Complexity

```
O(log N)
```

---

## Delete Root

Replace root with last element.

Move downward.

Called

```
Heapify Down

or

Sift Down
```

Complexity

```
O(log N)
```

---

## Peek

Largest (Max Heap)

or

Smallest (Min Heap)

Complexity

```
O(1)
```

---

# Heapify

Heapify restores the Heap Property.

Two types

- Heapify Up
- Heapify Down

---

# Build Heap

Convert an array into a Heap.

```cpp
make_heap(v.begin(), v.end());
```

Complexity

```
O(N)
```

---

# Heap Sort

Steps

1. Build Max Heap
2. Remove maximum repeatedly

Complexity

```
O(N log N)
```

Advantages

- In-place
- No extra memory

Disadvantage

- Not Stable

# 6. Top-K Problems

Top-K problems are among the most frequently asked Heap interview questions.

---

## Pattern 1

K Largest Elements

Use

```
Min Heap

Size = K
```

Reason

Smallest among the K largest elements stays at the top.

---

## Pattern 2

K Smallest Elements

Use

```
Max Heap

Size = K
```

---

## Pattern 3

K Closest Elements

Maintain a Heap using distance as priority.

---

## Pattern 4

Top K Frequent Elements

Use

```
Hash Map

+

Min Heap
```

---

## Pattern 5

Merge K Sorted Lists

Use

```
Min Heap
```

---

## Pattern 6

Kth Largest Element

Maintain

```
Min Heap

Size = K
```

---

## Pattern 7

Kth Smallest Element

Maintain

```
Max Heap

Size = K
```

---

# Why Min Heap for K Largest?

Find

```
Top 3
```

Maintain

```
Heap Size = 3

7 9 10
```

Top of Heap

```
7
```

```
11
```

comes,

remove

```
7
```

# 7. Heap vs BST vs Sorting

| Feature | Heap | BST | Sorting |
|----------|------|-----|----------|
| Search | O(N) | O(log N)* | O(log N) (Binary Search) |
| Largest | O(1) | O(log N) | O(1) |
| Insert | O(log N) | O(log N)* | O(N) |
| Delete Max | O(log N) | O(log N)* | O(N) |

\*Balanced BST

# 8. Common Patterns

| Pattern | Data Structure |
|----------|----------------|
| K Largest | Min Heap |
| K Smallest | Max Heap |
| Top K Frequent | Hash Map + Min Heap |
| Merge K Lists | Min Heap |
| Merge K Arrays | Min Heap |
| Running Median | Two Heaps |
| Sliding Window Median | Two Heaps |
| Task Scheduler | Max Heap |

---

# Running Median

Maintain

- Max Heap → Left Half
- Min Heap → Right Half

Balance both heaps after every insertion.

# 9. Common Mistakes

## Using Wrong Heap

Remember

K Largest

```
Min Heap
```

K Smallest

```
Max Heap
```

---

## Forgetting Heap Size

Maintain heap size

```
Exactly K
```

---

## Confusing Heap and BST

Heap

```
Only Root Guaranteed
```

BST

```
Entire Tree Ordered
```

---

## Assuming Heap is Sorted

Wrong.

Heap only guarantees

Parent

```
>=

or

<=

Children
```
