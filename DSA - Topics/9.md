# 1. Introduction to Hashing

## What is Hashing?

Hashing is a technique used to store and retrieve data efficiently.

Instead of searching linearly,

```
O(N)
```

we can access data in approximately

```
O(1)
```

using a **Hash Table**.

---

Example

```
Array

5 2 8 2 5 1
```

Frequency Table

```
1 → 1

2 → 2

5 → 2

8 → 1
```

Using Hashing, frequency counting becomes very easy.

---

# Why Hashing?

Hashing is used for:

- Fast Searching
- Frequency Counting
- Duplicate Detection
- Pair Sum Problems
- Caching
- Dictionaries
- Databases

---

# 2. Hash Table

A Hash Table stores data as

```
Key → Value
```

Example

```
"apple" → 5

"banana" → 2

"orange" → 8
```

---

## Hash Function

A Hash Function converts a key into an index.

Example

```
Key

42

↓

Hash Function

↓

Index

7
```

---

## Collision

Sometimes two keys produce the same index.

Example

```
15 → Index 3

25 → Index 3
```

This is called a **Collision**.

---

## Collision Handling

Common techniques

- Chaining
- Open Addressing

> In C++, `unordered_map` handles collisions internally.

---

# 3. Maps in C++

A Map stores data in

```
Key → Value
```

pairs.

---

## Ordered Map

```cpp
map<int, string> mp;
```

Properties

- Keys are sorted.
- Implemented using a Red-Black Tree.

Complexity

| Operation | Complexity |
|-----------|------------|
| Insert | O(log N) |
| Find | O(log N) |
| Erase | O(log N) |

---

Example

```cpp
map<int, string> mp;

mp[2] = "Bob";
mp[1] = "Alice";
mp[3] = "John";
```

Output Order

```
1 Alice

2 Bob

3 John
```

---

## Unordered Map

```cpp
unordered_map<int, string> mp;
```

Properties

- No ordering.
- Implemented using a Hash Table.

Average Complexity

| Operation | Complexity |
|-----------|------------|
| Insert | O(1) |
| Find | O(1) |
| Erase | O(1) |

Worst Case

```
O(N)
```

---

# Common Functions

Insert

```cpp
mp[key] = value;
```

Access

```cpp
mp[key];
```

Find

```cpp
mp.find(key);
```

Check existence

```cpp
if(mp.count(key))
```

Erase

```cpp
mp.erase(key);
```

Size

```cpp
mp.size();
```

---

# 4. Sets in C++

A Set stores **unique elements**.

Duplicates are automatically removed.

---

## Ordered Set

```cpp
set<int> st;
```

Properties

- Sorted
- Unique

Complexity

```
O(log N)
```

---

Example

```cpp
st.insert(5);
st.insert(3);
st.insert(5);
```

Stored

```
3 5
```

---

## Unordered Set

```cpp
unordered_set<int> st;
```

Properties

- Unique
- No order

Average Complexity

```
O(1)
```

---

# Common Functions

Insert

```cpp
st.insert(x);
```

Erase

```cpp
st.erase(x);
```

Find

```cpp
st.find(x);
```

Count

```cpp
st.count(x);
```

---

# 5. Map vs Unordered Map

| Feature | map | unordered_map |
|----------|-----|---------------|
| Order | Sorted | No Order |
| DS Used | Red-Black Tree | Hash Table |
| Insert | O(log N) | O(1) Avg |
| Search | O(log N) | O(1) Avg |
| Duplicate Keys | Not Allowed | Not Allowed |

---

# When to Use?

Use

```
map
```

when order matters.

Use

```
unordered_map
```

when fast lookup is needed.

---

# 6. Set vs Unordered Set

| Feature | set | unordered_set |
|----------|-----|---------------|
| Order | Sorted | No Order |
| Insert | O(log N) | O(1) Avg |
| Search | O(log N) | O(1) Avg |
| Duplicates | No | No |

# 7. Frequency Counting

One of the most common interview patterns.

Example

```cpp

```

Output

```
Number

↓

Frequency
```

Applications

- Majority Element
- Top K Frequent
- Count Distinct
- Duplicates

# 8. String Hashing (Introduction)

## What is String Hashing?

String Hashing converts a string into a numeric value (hash).

Instead of comparing whole strings repeatedly,

we compare their hash values.

---

Applications

- Rabin-Karp Algorithm
- Pattern Matching
- Detect Duplicate Strings
- Palindrome Queries
- Competitive Programming

---

## Polynomial Rolling Hash (Concept)

For string

```
abc
```

Hash is computed as

```
a × p^0 +
b × p^1 +
c × p^2
```

where

```
p

is usually

31

or

53
```

and values are taken modulo a large prime.

> You do **not** need to memorize the formula for interviews unless specifically asked.

---

## Prefix Hash

Prefix hashes allow substring hash queries in

```
O(1)
```

after

```
O(N)
```

preprocessing.

---

## When is String Hashing Used?

- Long string comparison
- Pattern matching
- Competitive Programming
- Advanced string algorithms

For most beginner interviews, knowing **unordered_map**, **unordered_set**, and frequency counting is more important.

---

# 9. Common Mistakes

## Using map instead of unordered_map

If ordering is not required,

use

```
unordered_map
```

for faster average performance.

---

## Accessing Missing Keys

```cpp
mp[key]
```

creates the key if it doesn't exist.

If you only want to check existence,

use

```cpp
mp.find(key)

or

mp.count(key)
```

---

## Forgetting Duplicates in Set

A Set stores only unique values.

---

## Assuming unordered_map is Ordered

It does **not** preserve insertion or sorted order.

---

## Ignoring Worst Case

`unordered_map` has average `O(1)` operations but worst-case `O(N)`.
